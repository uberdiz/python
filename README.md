# Python Practice

A collection of the Python exercises and small programs I wrote while learning the language. It is a learning record,
not a polished project. For my current work see [SAINT](https://github.com/uberdiz/SAINT) (a local voice assistant)
and my portfolio at https://sebastianai.vercel.app.

## What's here

- **`project_1.XX(...)` files** - numbered practice exercises: lists and strings, file reading/writing, dictionaries,
  functions, error checking, and word-frequency counting.
- **Small games** - for example `blackjack.py`, `Chess.py`, `Zork.py` (text adventure), `game.py`, `sandFall.py`
  and the Hangman, Rock-Paper-Scissors and Guess exercises.
- **Utilities** - `calculator.py`, `trig.py`, `Binary.py`, `textwriter.py`, and a quadratic-equation solver.
- **Stock-market simulator experiments** - `project_1.48(Stock_Market_Trader).py` and its follow-ups.

## Running a file

```bash
python calculator.py
```

Most files use only the standard library. Files that use `pygame` or other packages say so in their imports.
